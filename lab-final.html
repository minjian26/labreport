Results & Analysis

Starting with chaos game, the code is defined to the three vertices of a large equilateral triangle with a random point. At each iteration, it is picked one of the triangle's vertices randomly and move halfway toward it. Then, repeating this process thousands of times, the points accumulate into the shape of the sierpinski triangle. The code is adjusted with color by assigning a color to each vertex. For the times of iteration, it affects the clearness of the shape. After changing the number of the iterates, it becomes blurried if the iteration time is less than 30000. 



import matplotlib.pyplot as plt
from random import random, randint
import numpy as np

def midpoint(P, Q):
    return (0.5*(P[0] + Q[0]), 0.5*(P[1] + Q[1]))

# Define vertices
vertices = [(0, 0), (2, 2*np.sqrt(3)), (4, 0)]

# Number of points
iterates = 50000

# Preallocate arrays
x, y = [0]*iterates, [0]*iterates
colors = [0]*iterates  # New: color index
x[0], y[0] = random()*4, random()*2*np.sqrt(3)  # Start inside bounding triangle

for i in range(1, iterates):
    k = randint(0, 2)  # Choose a random vertex
    x[i], y[i] = midpoint(vertices[k], (x[i-1], y[i-1]))
    colors[i] = k  # Remember which vertex was chosen

# Define a color map: red, green, blue
colormap = {0: 'yellow', 1: 'green', 2: 'pink'}
point_colors = [colormap[k] for k in colors]

# Plotting
plt.figure(figsize=(8, 8))
plt.scatter(x, y, c=point_colors, s=0.1)
plt.title('Colored Sierpinski Triangle')
plt.axis('equal')
plt.axis('off')
plt.show()

Next, it comes to the Julia set. The code is pretty similiar to the code of Mandelbrot set. They both use @jit(nopython=true) to generate the sets. In mandelbrot set, it fixes the z_0=0 and and vary the parameter c. However, in Julia set, it fixes the parameter c and vary the z_0. They both use the function z_n+1=(z_n)(z_n)+c. The following is the code to generate Julia set. 


import numpy as np
import matplotlib.pyplot as plt
from numba import jit

@jit(nopython=True)
def julia_set(c, xmin, xmax, ymin, ymax, width, height, max_iter):
    r1 = np.linspace(xmin, xmax, width)
    r2 = np.linspace(ymin, ymax, height)
    n3 = np.empty((width, height))

    for i in range(width):
        for j in range(height):
            z = r1[i] + 1j * r2[j]
            n = 0
            while abs(z) <= 2 and n < max_iter:
                z = z*z + c
                n += 1
            n3[i, j] = n

    return n3

# Parameters for the plot
xmin, xmax, ymin, ymax = -1.5, 1.5, -1.5, 1.5
width, height = 800, 800  # Image resolution
max_iter = 256  # Number of iterations for accuracy

# Choose a value for the complex constant c
c = complex(-0.8, 0.156)

# Generate the Julia Set
n3 = julia_set(c, xmin, xmax, ymin, ymax, width, height, max_iter)

# Plotting the Julia Set
plt.figure(figsize=(10, 10))
plt.imshow(n3.T, extent=[xmin, xmax, ymin, ymax], cmap='hot', interpolation='bilinear')
plt.colorbar()
plt.title(f"Julia Set for c = {c}")
plt.show()
