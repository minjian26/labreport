Starting with chaos game, the code is defined to the three vertices of a large equilateral triangle with a random point. At each iteration, it is picked one of the triangle's vertices randomly and move halfway toward it. Then, repeating this process thousands of times, the points accumulate into the shape of the sierpinski triangle. The code is adjusted with color by assigning a color to each vertex. For the times of iteration, it affects the clearness of the shape. After changing the number of the iterates, it becomes blurried if the iteration time is less than 30000. 


import matplotlib.pyplot as plt
from random import random, randint
import numpy as np

def midpoint(P, Q):
    return (0.5*(P[0] + Q[0]), 0.5*(P[1] + Q[1]))

# Define vertices
vertices = [(0, 0), (2, 2*np.sqrt(3)), (4, 0)]

# Number of points
iterates = 50000

# Preallocate arrays
x, y = [0]*iterates, [0]*iterates
colors = [0]*iterates  # New: color index
x[0], y[0] = random()*4, random()*2*np.sqrt(3)

for i in range(1, iterates):
    k = randint(0, 2)  # Choose a random vertex
    x[i], y[i] = midpoint(vertices[k], (x[i-1], y[i-1]))
    colors[i] = k  # Remember which vertex was chosen

colormap = {0: 'yellow', 1: 'green', 2: 'pink'}
point_colors = [colormap[k] for k in colors]

plt.figure(figsize=(8, 8))
plt.scatter(x, y, c=point_colors, s=0.1)
plt.title('Colored Sierpinski Triangle')
plt.axis('equal')
plt.axis('off')
plt.show()

Next, using the same idea above, the code is defined four transformation functions. f1 creates the stem. f2 creates successively smaller ferns moving up and to the right. f3 creates the leaves on the right. f4 creates the leaves on the left. Then uses random.random() to probabilistically choose among the functions. Finally, generates and plots the points using matplotlib. 


import random
import matplotlib.pyplot as plt

def f1(x, y):
    x = 0
    y = 0.16 * y
    return x, y

def f2(x, y):
    x_new = 0.85 * x + 0.04 * y
    y_new = -0.04 * x + 0.85 * y + 1.6
    return x_new, y_new

def f3(x, y):
    x_new = 0.2 * x - 0.26 * y
    y_new = 0.23 * x + 0.22 * y + 1.6
    return x_new, y_new

def f4(x, y):
    x_new = -0.15 * x + 0.28 * y
    y_new = 0.26 * x + 0.24 * y + 0.44
    return x_new, y_new

probabilities = [0.01, 0.85, 0.07, 0.07]

def barnsley_fern(iterations):
    x, y = 0, 0
    points = []

    for _ in range(iterations):
        rand = random.random()
        if rand   < sum(probabilities[:1]):
            x, y = f1(x, y)
        elif rand < sum(probabilities[:2]):
            x, y = f2(x, y)
        elif rand < sum(probabilities[:3]):
            x, y = f3(x, y)
        else:
            x, y = f4(x, y)

        points.append((x, y))

    return points

# Generate points for the Barnsley Fern
iterations = 100000
fern_points = barnsley_fern(iterations)

# Plot the Barnsley Fern
x_vals, y_vals = zip(*fern_points)
plt.figure(figsize=(5, 7))
plt.scatter(x_vals, y_vals, s=0.1, color='green')
plt.title('Barnsley Fern')
plt.show()

Finally, it comes to L-system to generate fractal tree using initializeTurtle. It starts with defining functions to apply L-system rules, generating L-system string and drawing the L-system with turtle. Then, it defines the L-system rule and generate L-system strings 


initializeTurtle()
showturtle()

def apply_rule(char, rules):
    return rules.get(char, char)

def generate_lsystem(axiom, rules, iterations):
    current_string = axiom
    for _ in range(iterations):
        current_string = ''.join([apply_rule(char, rules) 
		for char in current_string])
    return current_string

def draw_lsystem(turtle_string, length, angle):
    stack = []
    for command in turtle_string:
        if command == 'F':
            forward(length)
        elif command == '+':
            left(angle)
        elif command == '-':
            right(angle)
        elif command == '[':
            position = (getx(), gety())
            heading_angle = heading()
            stack.append((position, heading_angle))
        elif command == ']':
            position, heading_angle = stack.pop()
            jump(position[0], position[1])
            face(heading_angle)

# Define the L-system rules
rules = {'F': 'FF+[+F-F-F]-[-F+F+F]'}

axiom = 'F'
iterations = 4

# Generate the L-system string
turtle_string = generate_lsystem(axiom, rules, iterations)

# Set up the turtle

Next, it comes to Hukbert curve. The Hilbert curve (also known as the Hilbert space-filling curve) is a continuous fractal space-filling curve first described by the German mathematician David Hilbert in 1891. It starts as a simple line that recursively folds to cover more space while always staying within a square boundary. It's a classic application of L-systems (Lindenmayer systems). The code is implemented using L-system rule. It generates the string with generate_lsystem(). Axiom: The starting string (initial state). Rules: Rewriting rules for characters. Iterations: How many times to apply the rules. By adjusting the number of iteration with 7, the gaps of lines become narrow. Continuing to increase the number with 8, it eventualy becomes a blue square. It depends on the initial size of the square. By increasing the size of the square, it can iterate more times.
