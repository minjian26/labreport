Starting with mandelbrot set, The Mandelbrot set is a fractal — a never-ending, self-similar pattern. It’s created by applying this formula repeatedly, which is z_n+1=z^2+C. The following codes generate and zoom into the Mandelbrot set using Numba's @jit optimization for speed. This function tests whether a given complex number c is in the Mandelbrot set. It starts with z=0 and repeatedly applies z=z*z+c. If ∣z∣>2, we consider it escaped and returns how many iterations it took to escape (or hits max). The Numba optimization (@jit(nopython=True)) is for performance. It is a great modular design to separate function for the set with high-resolution rendering 800x800. 


import numpy as np
import matplotlib.pyplot as plt

import numpy as np
import matplotlib.pyplot as plt
from numba import jit

@jit(nopython=True)
def mandelbrot(c, max_iter):
    z = 0
    n = 0
    while abs(z) <= 2 and n < max_iter:
        z = z*z + c
        n += 1
    return n

@jit(nopython=True)
def mandelbrot_set(xmin, xmax, ymin, ymax, width, height, max_iter):
    r1 = np.linspace(xmin, xmax, width)
    r2 = np.linspace(ymin, ymax, height)
    n3 = np.empty((width, height))

    for i in range(width):
        for j in range(height):
            n3[i, j] = mandelbrot(r1[i] + 1j * r2[j], max_iter)

    return n3

xmin, xmax, ymin, ymax = -2.0, 1.0, -1.5, 1.5
width, height = 800, 800
