Starting with mandelbrot set, The Mandelbrot set is a fractal — a never-ending, self-similar pattern. It’s created by applying this formula repeatedly, which is z_n+1=z^2+C. The following codes generate and zoom into the Mandelbrot set using Numba's @jit optimization for speed. This function tests whether a given complex number c is in the Mandelbrot set. It starts with z=0 and repeatedly applies z=z*z+c. If ∣z∣>2, we consider it escaped and returns how many iterations it took to escape (or hits max). The Numba optimization (@jit(nopython=True)) is for performance. It is a great modular design to separate function for the set with high-resolution rendering 800x800. 


import numpy as np
import matplotlib.pyplot as plt

import numpy as np
import matplotlib.pyplot as plt
from numba import jit

@jit(nopython=True)
def mandelbrot(c, max_iter):
    z = 0
    n = 0
    while abs(z) <= 2 and n < max_iter:
        z = z*z + c
        n += 1
    return n

@jit(nopython=True)
def mandelbrot_set(xmin, xmax, ymin, ymax, width, height, max_iter):
    r1 = np.linspace(xmin, xmax, width)
    r2 = np.linspace(ymin, ymax, height)
    n3 = np.empty((width, height))

    for i in range(width):
        for j in range(height):
            n3[i, j] = mandelbrot(r1[i] + 1j * r2[j], max_iter)

    return n3

xmin, xmax, ymin, ymax = -2.0, 1.0, -1.5, 1.5
width, height = 800, 800

Next, it comes to the Julia set. The code is pretty similiar to the code of Mandelbrot set. They both use @jit(nopython=true) to generate the sets. In mandelbrot set, it fixes the z_0=0 and and vary the parameter c. However, in Julia set, it fixes the parameter c and vary the z_0. They both use the function z_n+1=(z_n)(z_n)+c. The following is the code to generate Julia set. 


import numpy as np
import matplotlib.pyplot as plt
from numba import jit

@jit(nopython=True)
def julia_set(c, xmin, xmax, ymin, ymax, width, height, max_iter):
    r1 = np.linspace(xmin, xmax, width)
    r2 = np.linspace(ymin, ymax, height)
    n3 = np.empty((width, height))

    for i in range(width):
        for j in range(height):
            z = r1[i] + 1j * r2[j]
            n = 0
            while abs(z) <= 2 and n < max_iter:
                z = z*z + c
                n += 1
            n3[i, j] = n

    return n3

# Parameters for the plot
xmin, xmax, ymin, ymax = -1.5, 1.5, -1.5, 1.5
width, height = 800, 800  # Image resolution
max_iter = 256  # Number of iterations for accuracy

# Choose a value for the complex constant c
c = complex(-0.8, 0.156)

# Generate the Julia Set
n3 = julia_set(c, xmin, xmax, ymin, ymax, width, height, max_iter)

# Plotting the Julia Set
plt.figure(figsize=(10, 10))
plt.imshow(n3.T, extent=[xmin, xmax, ymin, ymax], cmap='hot', interpolation='bilinear')
plt.colorbar()
plt.title(f"Julia Set for c = {c}")
plt.show()
