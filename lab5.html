Results & Analysis

First, it needs to initialize the turtle. Then, it define a fractal tree function with length and depth. Setting "if" command, it is to input certain parameters for length and depth if depth == 0. Next, set up the turtle's starting position and orientation. The starting position at the bottom center of the canvas Then, set the length and depth for the fractal tree. After initialing length of the main trunk and Recursion depth which is number of branching levels, finally the fractal tree is displayed. 


def fractal_tree(length, depth):
    if depth == 0:
        return
    else:

        forward(length)
        left(30)

        fractal_tree(length * 0.7, depth - 1)

        right(60)

        fractal_tree(length * 0.7, depth - 1)

        left(30)
        backward(length)

initializeTurtle(initial_window_size=(500, 500))

face(0)
color('green')  # Set the pen color

length = 100  
depth = 7    
		
# Draw the fractal tree

# Display the drawing

Further, I learn to draw fractal tree with many branchers by extending the previous code. Similiarly, it needs to define a function. However, the function need to include the branch length, shorten by, and angle. If the branch length is greater than 3, then it moves forward with the certain branch length. Importing the relationship between the branch length and shorten by, the new length = branch length - shorten by. Then, angle is changed to left and right. It is continued to build tree. Then, it is to set up the turtle's starting position and orientation. By imputting three parameters, it finally displays the fractal tree. 


def build_tree(branch_length, shorten_by, angle):
    if branch_length > 3:

        forward(branch_length)

        new_length = branch_length - shorten_by

        left(angle)

        build_tree(new_length, shorten_by, angle)

        right(angle * 2)

        build_tree(new_length, shorten_by, angle)

        left(angle)

        backward(branch_length)

initializeTurtle(initial_window_size=(800, 800))

jump(400, 600)  
face(0)
color('green') 

build_tree(80, 8, 25)

show()
